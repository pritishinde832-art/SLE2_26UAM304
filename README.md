# BFS vs DFS Profiling

## Project Title
Comparative Performance Analysis of BFS and DFS Algorithms

## Objective
To compare Breadth First Search (BFS) and Depth First Search (DFS) based on nodes expanded and execution time.

## Description
This project implements BFS and DFS algorithms using Python. Both algorithms search for a goal node in a graph. The program measures execution time using the `time` module and counts the number of nodes expanded.

## Technologies Used
- Python
- Time module
- Graph data structure
- BFS and DFS algorithms

## How to Run
1. Install Python.
2. Save the code as `sle2_bfs_vs_dfs.py`.
3. Open the terminal in the project folder.
4. Run the command:

```bash
python sle2_bfs_vs_dfs.py
```

## Output
The program displays:
- BFS nodes expanded
- BFS execution time
- DFS nodes expanded
- DFS execution time

## Conclusion
This project compares BFS and DFS performance. The execution time may vary between runs, and the number of nodes expanded depends on the graph and traversal order.
